# Image Sources

Every image used in the paper is openly licensed and is included in [`data/`](data/). File names follow `<scene>_<pick|altN>_<source>-<id>.<ext>`: `pick` is the photo used in the paper and `altN` an alternative for the same scene. Licences:

- **Unsplash** and **Pexels** photos are used under the [Unsplash License](https://unsplash.com/license) and [Pexels License](https://www.pexels.com/license/), which allow free use without permission. Credit is still given here.
- **Wikimedia Commons** photos are used under the licence stated on each file page. Check that page for the licence and the author credit to reproduce with the image.

Most files are the `.avif` copies served by Unsplash, which are smaller than the originals; detector scores on full-resolution downloads can differ slightly.

The earlier image list (press and stock photos from Getty, Alamy, 123RF, and similar sites) has been retired, because those images could not be published with the paper.
